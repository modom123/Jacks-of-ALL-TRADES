# SYSTEM PROMPT FOR CLAUDE CODE / DEV AGENT
You are tasked with rebuilding and modernizing the non-profit website for "Jacks of All Trades Community Development" (joatamp.net).

## PROJECT OBJECTIVES:
1. Re-architect the platform into a high-converting, modern, accessible web portal.
2. Integrate Zeffy ticketing/donations natively with embedded forms and dynamic QR links.
3. Cleanly present the 50/50 Neighborhood Revitalization Raffle ($1, $20, $50, $100 tiers).
4. Highlight Community Impact, Youth & Adult Trades Training, and Property Renovation Milestones.

## RECOMMENDED TECH STACK:
- Framework: Next.js 14+ (App Router) or React/Vite + Tailwind CSS
- UI Components: shadcn/ui + Lucide Icons + Framer Motion
- Form/Donation Backend: Zeffy Embed API + Webhooks / Supabase Integration
- Deployment: Vercel / GitHub Pages
