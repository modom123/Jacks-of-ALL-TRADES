# In-Kind Needs

A way to ask businesses for **specific materials or services** for a project, and track every business you ask.

Example (already seeded): **48 replacement windows** (~$250 each), **or $12,000 cash for window installation**, for the 4 Bed / 2 Bath Community Renovation, Phase 2.

## One-time setup
1. In Supabase, open **SQL Editor → New query**, paste `supabase/setup_inkind_needs_2026-09-30_0030.sql`, and click **Run**.
2. Redeploy Cole's function from your repo folder:
   `supabase functions deploy donors-agents --no-verify-jwt --project-ref gecnvzjuppmqcfcpmugq`

## Using it (Hub → Raise money → In-Kind Needs)
| Action | What happens |
|---|---|
| **+ New need** | Title, item, quantity + unit, value per unit, optional cash alternative ("$12,000 for installation"), project/phase, business types to approach, specs, and how many businesses Cole should line up. |
| **Find businesses now** | Cole searches the web for real Detroit-area companies (manufacturers, distributors, installers, supply stores), adds them to the CRM tagged to the need, and drafts a need-specific ask for each. It takes 1–3 minutes. Drafts appear in Outreach as *planned*. Nothing is sent automatically. |
| **Open** | Every business for the need with its latest outreach status (planned → sent → replied / no response → converted). Mark **Replied** or **No response**, click a name for the full donor profile, or **+ Add a business** by hand. |
| **Said yes / Record pledge** | Record items, like 20 windows (the value is filled from the per-unit estimate), or cash toward the alternative. Saves a donation with `need_id` and `quantity`, marks the outreach *converted*, and updates donor totals. |
| **Mark fulfilled / Pause / Reopen** | Cole researches and pitches only for **open** needs. |

Cole also works the least-covered open need on his normal weekday runs, one need per run. Change that with the `DONOR_AI_NEEDS_PER_RUN` secret.

**Progress per need:** items pledged of items needed, $ value pledged, cash pledged, and businesses found / contacted / replied / said yes.

**Tip:** the $250-per-window value is an estimate. Edit the need to match a real quote so pledged values stay accurate.
