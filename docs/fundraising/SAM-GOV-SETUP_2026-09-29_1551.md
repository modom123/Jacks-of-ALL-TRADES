# SAM.gov in the Command Center

The Command Center's Grants engine can now pull live federal opportunities from **SAM.gov**. It sits alongside Grants.gov, which already worked.

## One-time setup (run from the repo root)

```bash
supabase secrets set SAM_API_KEY=<your SAM.gov public API key>
supabase functions deploy grants-search
supabase functions deploy grants-daily --no-verify-jwt
```

Or go to Supabase Dashboard → Edge Functions → Secrets → add `SAM_API_KEY`.

**Never** put the key in `assets/js/config.js` or commit it to git.

## Using it
- **Find leads** → Source: **SAM.gov**, then enter a keyword. The keyword is matched against notice titles, e.g. `construction`, `training`, `renovation`.
- **Daily auto-finder:** once the key is set, `grants-daily` fills up to `SAM_DAILY_TARGET` (default 3) of the day's leads from SAM.gov. Grants.gov fills the rest.

## Notes
- SAM.gov lists mostly federal **contract** opportunities: solicitations, sources sought, and special notices. Most federal **grants** are on Grants.gov.
- SAM.gov public API keys **expire every 90 days**. To renew, go to sam.gov → Profile → Account Details → regenerate, then run `supabase secrets set` again.
- `SAM_LOOKBACK_DAYS` (default 60) controls how far back postings are searched.
