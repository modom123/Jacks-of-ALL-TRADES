# Grants Engine — three AI agents for grant funding

A dedicated grants team in the Command Center. Each agent owns one stage; a human reviews and approves before anything is sent.

| Agent | Role | Does |
|---|---|---|
| **Gwen** | Grant Prospector | Finds & qualifies foundation/corporate/government grants that fit our mission; scores fit; flags amounts & deadlines as **verify**. |
| **Rex** | Grant Outreach | Drafts (and, once sending is wired, sends) funder **intro emails** and **call scripts** to program officers — business-to-business cultivation. |
| **Wes** | Grant Writer | Drafts **LOIs / full proposals / budgets**, then **post-submission follow-ups**. |

## Daily goals & progress tracking
The Grants view opens with a **Today's goals** panel and the same two bars appear on the main **Dashboard**:

- **Grants found today → 10** — the **"Find today's 10"** button pulls the remaining count from Grants.gov in one click.
- **Proposals sent today → 5** — each card has **"Mark submitted today"** (sets status → submitted, dated today) so it counts toward the goal.

Targets live in `config.js` → `window.JOAT.GRANTS_GOALS` (`findPerDay`, `proposalsPerDay`). Each lead card also shows a **Stage x/6** progress bar so you can see exactly where every proposal stands.

## Where it lives
**Command Center → Fundraising → Grants.** Every opportunity is one row moving through:
`identified → qualified → contacted → drafting → submitted → follow_up → awarded / declined`.
The applicant legal name (**Jacks of All Trades**) and **EIN 41-2680557** are baked into Wes's proposals automatically.

Per lead you can, in one card: edit funder details, capture the (verified) contact, set the requested amount and dates, and have **Rex** draft the intro email + call script and **Wes** draft the proposal + follow-up — each with its own Draft / Copy button.

## Finding leads — two sources
In **Grants → Find grant leads**, pick a **Source**:

- **Grants.gov (live federal)** — pulls **real** federal opportunities with their **award ceiling/floor** (the grant size), close dates, agency, and eligibility, straight from the free public Grants.gov API (no key, no scraping). This is what lets Wes size a proposal to the actual award range.
- **AI shortlist (Gwen)** — for **foundations & corporate** funders (no single free API), Gwen suggests a shortlist from her knowledge, with every amount/deadline flagged **verify**.

> **Why the API, not a scraper:** scrapers break the moment a site changes and often violate terms of service. Grants.gov publishes an official API with structured award amounts — reliable and maintainable. Foundation/corporate discovery has no free equivalent; that stays AI-shortlist + human verification (a paid source like Candid/Foundation Directory can be added later).

## Turn it on
1. Run `supabase/schema_grants_2026-09-15_1610.sql` in the Supabase SQL Editor.
2. Deploy the functions:
   - `supabase functions deploy ai-agent` (needs `ANTHROPIC_API_KEY` — powers Gwen/Rex/Wes drafting)
   - `supabase functions deploy grants-search` (no key — live Grants.gov federal search)
3. **Grants → Find leads** → pick a source → work each card.

## Guardrails (important)
- **Verify everything.** The agents never confirm a deadline, dollar amount, program officer, email, or phone as fact — they use `[verify]` / `[placeholder]`. Confirm each before you send or apply.
- **No invented financials or metrics.** Wes leaves `[EIN]`, `[501(c)(3) date]`, budget figures, and outcome numbers as placeholders for the team to fill.
- **Outreach is B2B.** Contacting a foundation's program officer or a government grant office is institutional cultivation — not the consumer marketing that the raffle SMS/voice rules cover. Still: keep it professional and honor any do-not-contact request.

## Sending

**Email is wired.** Each grant card has a **Send email** button on Rex's intro email and Wes's follow-up. It sends to the funder's saved contact email via the `send-email` Edge Function, using **your signed-in staff token** (random visitors can't send from your domain). Sending the intro email auto-advances the lead to **contacted**.

To turn on email sending:
1. Create a **Resend** account and verify your sending domain (joatamp.org).
2. Set secrets and deploy:
   ```
   supabase secrets set RESEND_API_KEY=re_xxxxxxxx
   supabase secrets set EMAIL_FROM="Jacks of All Trades <grants@joatamp.org>"
   supabase functions deploy send-email
   ```
   (Prefer a different provider? Swap the `sendViaResend()` body in `supabase/functions/send-email/index.ts` for SendGrid/Postmark/Mailchimp — keep the sign-in check.)
3. Confirm the funder's **contact email** on the card, Save, then **Send email**.

**Still to wire — phone calls.** Rex's call scripts are drafts today; placing calls needs a Twilio `place-call` function (text-to-speech or a recording). Funder calls are B2B, so lighter compliance than the raffle voice line.
